# BGU Radio Live — Chrome prototype

This standalone Manifest V3 extension only plays or pauses the BGU Radio live stream. It uses the station's public MP3 stream at `https://bguradio.co/listen/bguradio/radio.mp3`. A hidden offscreen document keeps playback running after the toolbar popup closes.

## Load in Chrome
1. Download this repository or the `extension` folder.
2. Open `chrome://extensions` and enable Developer mode.
3. Choose **Load unpacked** and select this folder.

The extension is a separate prototype in this repository. It shares the website's visual direction, not its runtime or page code.
